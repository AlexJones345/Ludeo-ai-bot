p2p bot

This repository contains a Python bot (in p2pbot.py).

📌 GitHub Pages Notes

GitHub Pages can host this site (docs/) as a static website, but it cannot run Python code on the server.

⚙️ How to Run the Bot (Locally or on a Server)

  1. Install Python 3.10+ (python.org).
  2. Create and activate a virtual environment:
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
  1. Install dependencies (if any). Add them to requirements.txt if you have dependencies.
  2. Run the bot:
python p2pbot.py

📄 Repository Structure

  • p2pbot.py - main bot script
  • docs/ - static site content served by GitHub Pages
  • .github/workflows/ - GitHub Actions workflow that deploys the site

🔗 Want to Deploy the Bot?

To run this bot online you need a runtime host (e.g., a VPS, Heroku, Railway, or a container service). GitHub Pages only serves static content.
